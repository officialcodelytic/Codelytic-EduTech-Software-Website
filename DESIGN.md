## Brand & Style

This design system establishes a high-performance corporate tech aesthetic tailored for modern educational platforms, enterprise learning suites, and software products. It combines corporate reliability with modern edtech innovation—projecting intelligence, structural clarity, and forward momentum.

### Core Attributes
- **Intellectual & Scalable:** Clean architecture designed for data-dense learning environments, analytics dashboards, and interactive coursework without visual fatigue.
- **Vibrant Precision:** Grounded by institutional dark slates and crisp neutral canvases, punctuated by high-energy blues and gradient transitions derived from the mosaic mark.
- **Architectural Polish:** Subtle containment, micro-radii, hairline borders, and airy spacing that emphasize content hierarchy and executive-grade presentation.

### Aesthetic Direction
A tailored synthesis of **Corporate Modern** and **High-Contrast Digital SaaS**. Interfaces leverage pure white and pale slate surfaces, accented with gradient glows, hairline boundaries, and sharp geometric modularity reminiscent of the identity's pixel-mosaic construct.

## Colors

The color palette is built around the spectrum of the brand mark: deep indigo, electric cyan, and royal blue balanced against a high-clarity slate foundation.

### Semantic Palette & Roles
- **Primary (`#1A56DB` - Royal Blue):** The primary anchor for interactive touchpoints, main calls to action, active navigation states, and primary brand accents.
- **Secondary (`#00C5FF` - Electric Cyan):** High-impact accent for metric callouts, progress completion meters, real-time indicators, and terminal-end gradient stops.
- **Tertiary (`#6C2BD9` - Deep Indigo / Purple):** Evocative of advanced features, specialized educational tracks, premium tiers, and initial gradient anchors.
- **Neutral Surface & Text (`#0F172A`, `#1E293B`, `#334155`):** 
  - `#0F172A` (Slate 900) for primary headings and prominent iconography.
  - `#1E293B` (Slate 800) for regular body copy and table headers.
  - `#334155` (Slate 700) for sub-labels and supporting metadata.
  - `#64748B` (Slate 500) for disabled labels, placeholders, and subtle hints.
  - `#F8FAFC` to `#FFFFFF` for pristine canvas backdrops and layered surface cards.
  - `#E2E8F0` for structural hairlines and table cell dividing rules.

### Brand Gradients
- **Accent Gradient:** Linear `135deg` from `#6C2BD9` (0%) to `#1A56DB` (55%) to `#00C5FF` (100%), reserved for featured state badges, primary action buttons, key metrics, and banner highlights.

## Typography

Plus Jakarta Sans provides geometric rigor paired with modern humanistic open counters, optimizing readability for enterprise consoles, code snippets, learning curricula, and dense operational tables.

### Type Rules
- **Headlines:** Use tight tracking (`-0.02em` to `-0.03em`) and heavy weights (700-800) for structural impact in educational and platform hero sections.
- **Body & Data:** Standard weights (400-500) paired with generous line heights (`1.5` to `1.6`) ensure long-form instructional material and complex technical briefs remain fatigue-free.
- **Labels & Micro-copy:** Uppercase or small tracking adjustments (`0.04em`) are dedicated to status pills, step indicators, and column descriptors.

## Layout & Spacing

A responsive 12-column grid provides structure across complex dashboards and public-facing educational catalogs.

### Grid Structure
- **Desktop (>= 1280px):** 12-column fluid grid, max canvas width of `1440px`, centered with `margin-desktop` (3rem / 48px) and `gutter-lg` (2rem / 32px).
- **Tablet (768px - 1279px):** 8-column layout, `gutter` (1.5rem / 24px), outer margins set to `margin` (2rem / 32px).
- **Mobile (< 768px):** 4-column layout, `gutter-sm` (1rem / 16px), margins compressed to `margin-mobile` (1rem / 16px).

### Spacing Philosophy
Rhythm is disciplined around multiples of 4px and 8px. Compact spacing (`space-xs`, `space-sm`) governs controls, metadata badges, and form structures; expansive spacing (`space-xl`, `space-2xl`) dictates educational module separation and feature sections.

## Elevation & Depth

Visual hierarchy leverages crisp hairline boundaries, multi-layered tinted ambient shadows, and luminous gradient accents to establish clean separation between surfaces.

### Surface Tiers
- **Canvas Base:** `#F8FAFC` (Slate 50) as the global workspace backdrop.
- **Surface Elevation 0 (Flat Container):** `#FFFFFF` framed by a `1px` border in `#E2E8F0` with no shadow, ideal for data tables, form groupings, and nested module panels.
- **Surface Elevation 1 (Card Default):** `#FFFFFF` paired with subtle ambient blur: `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 4px 12px -2px rgba(15, 23, 42, 0.06);` along with a delicate hairline border `#F1F5F9`.
- **Surface Elevation 2 (Card Hover & Modals):** Enhanced vertical lift tinted with faint brand blue: `box-shadow: 0 10px 25px -5px rgba(26, 86, 219, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04);`.
- **Focus & Selection Aura:** `0 0 0 3px rgba(0, 197, 255, 0.25)` providing vibrant accessibility indicators without layout shift.

## Shapes

The design system employs moderate corner rounding (`0.5rem` / `8px` base) to balance tech authority with friendly, human-centered educational engagement.

### Geometry Hierarchy
- **Standard Controls & Elements (0.5rem / 8px):** Applied to buttons, text inputs, dropdown triggers, and select controls.
- **Cards & Modals (rounded-lg: 1rem / 16px):** Outer platform modules, course cards, assessment containers, and dialog sheets.
- **Hero Containers & Feature Panels (rounded-xl: 1.5rem / 24px):** Major educational dashboard widgets, high-level analytics sections, and marketing callouts.
- **Pills / Full Radius (`9999px`):** Status chips, counter badges, avatar frames, and segmented toggle pills.

## Components

### Buttons
- **Primary:** Gradient fill `linear-gradient(135deg, #1A56DB 0%, #00C5FF 100%)` or solid `#1A56DB`, text `#FFFFFF`, font `label-lg`, height `42px`, padding `0 1.25rem`, border radius `0.5rem`. On hover: subtle brightness shift and `0 4px 12px rgba(26, 86, 219, 0.25)` drop shadow.
- **Secondary / Outline:** Background `#FFFFFF`, border `1px solid #CBD5E1`, text `#0F172A`. Hover: border `#1A56DB`, text `#1A56DB`, background `#F8FAFC`.
- **Ghost:** Background transparent, text `#334155`. Hover: background `#F1F5F9`, text `#0F172A`.

### Cards & Learning Tiles
- Background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius `1rem`, padding `1.5rem`.
- Course and content cards include a top accent line or thumbnail region, an interactive hover lift transition (`transform: translateY(-2px)`), and an intensified shadow with cyan/blue ambient glow.

### Chips & Tags
- **Status Badges:** Height `24px`, padding `0 0.625rem`, radius `9999px`, font `label-sm`.
  - *Active / Success:* Background `#ECFDF5`, text `#065F46`, border `1px solid #A7F3D0`.
  - *In Progress / Tech Focus:* Background `#EFF6FF`, text `#1E40AF`, border `1px solid #BFDBFE`.
  - *Special / Premium:* Background `#F5F3FF`, text `#5B21B6`, border `1px solid #DDD6FE`.

### Input Fields & Controls
- **Text Inputs:** Height `42px`, background `#FFFFFF`, border `1px solid #CBD5E1`, radius `0.5rem`, padding `0 0.875rem`, text `#0F172A`, placeholder `#94A3B8`.
- **Focus State:** Border color `#1A56DB`, outline `3px solid rgba(0, 197, 255, 0.2)`.
- **Checkboxes & Radios:** `18px` by `18px`, border `1.5px solid #94A3B8`. When checked: fill `#1A56DB` with crisp white icon checkmark.

### Additional Solution Components
- **Progress Trackers:** High-contrast rail in `#F1F5F9` with fill in `linear-gradient(90deg, #1A56DB, #00C5FF)` with `0.25rem` height.
- **Metric Stat Counters:** Slate 900 numeric value (`headline-lg`), Slate 500 title (`label-sm`), paired with micro-trend pills and electric cyan sparkline accents.
